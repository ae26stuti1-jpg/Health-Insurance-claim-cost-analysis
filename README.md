# Health Insurance Claim Cost Analysis

## About the Project

This is an academic project that examines the relationship between selected policyholder characteristics and annual health insurance claim costs.

The project uses a simulated dataset and applies basic statistical analysis and multiple linear regression to understand factors associated with differences in claim costs.

## Objective

The main objective of the project is to study whether variables such as age, BMI, number of children and smoking status are associated with annual health insurance claim costs.

## Data

The dataset contains 180 simulated policy records.

The variables included are:

- Age
- Sex
- BMI
- Number of children
- Smoking status
- Region
- Annual claim cost

The data are simulated and are used only for academic analysis.

## Statistical Methods

The analysis includes:

- Descriptive statistics
- Correlation analysis
- Multiple linear regression
- Interpretation of regression coefficients
- R-squared and adjusted R-squared

Annual claim cost is taken as the dependent variable, while age, BMI, number of children and smoking status are used as explanatory variables.

## SQL Analysis

SQL is used for basic data analysis, including:

- Average claim cost by smoking status
- Average claim cost by age group
- Number of policies by region

## Tools Used

- Microsoft Excel
- SQL
- Statistics
- Regression Analysis

## Limitations

The dataset is simulated and does not represent actual insurance company data.

The project is intended as an academic exercise to understand the application of statistical and regression methods to an insurance-related problem.

## Conclusion

The project demonstrates how basic statistical methods and multiple regression can be used to study variation in health insurance claim costs and identify factors associated with higher predicted costs.
